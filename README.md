# Weather Shine 🌤️

**Weather Shine** is a Flutter-based weather application that allows users to search for a location and view real-time weather informations with description and country details.  
The app integrates **multiple external APIs** to deliver a more informative and user-friendly experience (OpenWeather API, Wikipedia API and REST Countries API ).

---

## ✨ Overview

Weather Shine enables users to enter a place name and instantly receive current weather details along with contextual information about the location.  
The project demonstrates how to combine multiple APIs in a single Flutter application and present the data cleanly in a mobile-friendly UI scrollable form.

---

## 🚀 Key Features

- 🔎 **Search by Location**  
  Users can input a city or place name to retrieve relevant information.

- ☁️ **Real-Time Weather Data**  
  Fetches current weather conditions using the **OpenWeather API**.

- 🌍 **Country Information Lookup**  
  Uses the **REST Countries API** to retrieve country-related data for searched locations.

- 📚 **Location Context & Description**  
  Integrates the **Wikipedia API** to provide brief background or descriptive information about searched places.

- 📱 **Mobile-First UI**  
  Built with Flutter to ensure a responsive and smooth experience on mobile devices.
